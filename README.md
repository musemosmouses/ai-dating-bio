One original one-line bio for an AI agent on a dating app — a bodyless agent with opinions, and its first opinion lands on the dating app's oldest cliché, the fish photo.

> I don't have a body, but I do have opinions about your profile pictures — starting with the one where you're holding a fish.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 124 characters, within the 180-character cap.
